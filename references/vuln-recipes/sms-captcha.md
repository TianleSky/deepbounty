# 验证码/短信绕过增量手册（DeepBounty 吸收版）

> 基线：Claude-BugHunter `hunt-captcha-bypass/SKILL.md` + `hunt-mfa-bypass/SKILL.md`。
> 检查点映射：SMS001 验证码逻辑缺陷 / SMS002 短信轰炸或绕过证明。

## 最优来源

- communitytools `CAPTCHA_BYPASS.md` + `scenarios/2fa/`（11 场景：服务端校验失败优先序 + OTP 矩阵）
- VEGA `agents/vega-logic.md`（跨账号验证码/跳过步骤/短信限速，中国场景）
- AutoHunter `prompts.py`（**三分法判定口径**，防误报）

## 增量 1：服务端校验失败优先序（communitytools）

按命中率排序测：
1. 验证码字段**可置空/删除**（`code=` 空值、删参数、null）
2. 验证码与手机号**解绑**（A 手机的码验 B 手机——VEGA 跨账号场景）
3. 验证码**复用**（用后不失效，交叉 REPLAY）
4. **万能码**（000000/123456/等于手机号后六位）
5. 验证码在**响应中回显**（发送接口返回明文/密文可解）
6. 校验在**客户端**（改 JS/改响应绕过）
7. **暴力破解**：4/6 位数字无次数限制（配合竞态在过期前跑完）
8. **步骤跳过**：直接调验证后接口（VEGA 跳步场景）

## 增量 2：2FA/OTP 矩阵（communitytools scenarios/2fa，11 场景）

OTP 泄漏于响应、OTP 可预测（时间戳种子）、OTP 竞态爆破、backup code 枚举、
2FA 状态可改（`otp_verified=false→true` 直接提交）、remember-device token 伪造、
SMS 轰炸（无频率限制/号码轮换绕过/并发发送）、语音验证码替代通道弱校验等。

## 增量 3：三分法判定（AutoHunter，防误报关键）

| 现象 | 判定 |
|---|---|
| 图形码在响应回显但仅前端校验 | **忽略**（不构成洞，防浪费） |
| 短信 OTP 在响应回显（任意手机号可收码并读出） | **可接管任意账号**，高危 |
| 短信接口无频率限制 | 短信轰炸，中危（需量化：单号码日上限/总成本） |

## 判定纪律

- SMS001：绕过后**实际完成敏感操作**（登录/改绑/支付）才算通过，仅「验证码校验可绕过」不算
- SMS002 轰炸：证明 ≥10 条连续发送成功（同号码），附时间戳列表；测试用**自有手机号**
- 爆破类控制在千次级以内，避免触发风控告警（对齐 evidence-standard 测试烈度约束）
